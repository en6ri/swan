Konferencja Ignite ruszyła 17 listopada w San Francisco. Według Microsoftu Copilot łączy tryby Chat, Cowork, Code i Autopilot. Aplikacje Word, Excel i PowerPoint działają już w aplikacji Copilot, a według Windows Mode Autopilot i Copilot Workspaces są udostępniane w ramach programu Frontier. Firma zapowiedziała też wtyczki dla aplikacji biznesowych, zaczynając od Dynamics 365, oraz partnerstwo, które ma wprowadzić Salesforce do Copilota.

Microsoft udostępnił ogólnie modele Code 2 i Code 2 Flash w GitHub Copilot, są też dostępne w Foundry, oraz model Microsoft-Decision-1.1, z którego według firmy korzystało już ponad 4000 klientów. Według Windows Mode Copilot w Windows ma wkrótce wyszukiwać, przenosić i zmieniać nazwy plików, najpierw na komputerach Copilot+. Według Microsoftu Agent 365 zarządza już ponad 50 mln agentów.
